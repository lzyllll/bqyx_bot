# AstrBot 爆枪英雄插件 (astrbot_plugin_bqyx)

基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 与 `bqyx_api` 开发的爆枪英雄军队与账号管理插件。

---

## 功能特性

- **军队绑定与管理**：
  - `绑定军队 <军队ID>`：群绑定目标军队
  - `绑定游戏名 <角色名>`：按游戏角色名绑定（支持重名候选选择，30秒会话交互）
  - `绑定uid <UID>`：按游戏 UID 绑定
  - `绑定账号 <4399账号>`：按 4399 用户名绑定
  - `一键绑定`：群成员昵称与军队成员全自动匈牙利算法最优匹配绑定
  - `我的绑定`：查看当前绑定的游戏角色与存档
  - `我的信息`：查看个人日贡、周贡与任务进度
  - `免at添加 / 删除 / 列表`：群通知免 @ 名单配置

- **数据与面板查询**：
  - `我的战力 [@用户]`：查询角色战力面板、属性加成、模块加成与武器数据汇总
  - `我的贡献 [@用户] [年月]`：查看 GitHub 风格月度日历贡献墙
  - `查修罗 [@用户] [图片|文本]`：查询修罗塔挑战进度
  - `军队信息 [图片|文本]`：查看军队战力、等级、人数等基本信息
  - `查成员 [图片|表格|文本]`：查看军团成员列表及贡献数据（支持导出 Excel 表格）
  - `查争霸 [图片|表格|文本]`：查看争霸据点分配与战况
  - `/members /union /domain /pk <军队ID>`：跨群快速查询指定军队信息
  - `查PK [图片|文本]`：军队 PK 排行榜
  - `查日贡 / 查周贡 [阈值]`：达标与未达标成员筛选，支持 `查日贡@` / `查周贡@` 群内点名提醒
  - `查物品 [@用户]`：查询角色背包物品，并在有变动时自动生成对比图

- **实时与历史军队排行**：
  - `实时军队排行 [范围]`：全服军队总排行（支持区间如 `1-50` 或中心名次）
  - `今日日贡排行 [范围]`：全服今日新增贡献实时排行榜
  - `昨日日贡排行 [范围]`：昨日日贡归档排行榜
  - `本周周贡排行 [范围]`：本周新增周贡排行榜
  - `上周周贡排行 [范围]`：上周新增周贡排行榜
  - `昨日贡献 [阈值]`：军团内昨日贡献图片渲染

- **自动化与稳定性**：
  - 每日 23:30 自动采集绑定军队成员快照
  - 每日 23:59 自动采集全服前 1000 军队排行
  - 每日 00:10 自动清理过期指令调用统计
  - 滑动窗口群级别与全局限流保护（支持 `统计RPM` 与 `统计今日调用`）

## 配置说明

可在 AstrBot 管理面板的「插件配置」中可视化配置，或在当前目录创建 `.env` 文件：

| 配置项 | 环境变量 | 说明 | 默认值 |
|---|---|---|---|
| `username` | `BQYX_USERNAME` | 4399 代理账号用户名 | `""` |
| `password` | `BQYX_PASSWORD` | 4399 代理账号密码 | `""` |
| `arch_index` | `BQYX_ARCH_INDEX` | 代理账号存档槽位 (0-7) | `4` |
| `snapshot_retention_days` | `BQYX_SNAPSHOT_RETENTION_DAYS` | 成员快照保留天数 | `63` |
| `union_snapshot_retention_days` | `BQYX_UNION_SNAPSHOT_RETENTION_DAYS` | 军队排行保留天数 | `15` |
